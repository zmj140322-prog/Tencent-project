# 悦读 · 数字藏书楼

腾讯实训营项目 —— 新中式风格的图书馆 Web 应用，支持图书检索、**预约借阅 · 到馆办理**、扫码借还、图书评论评分与自习室选座。

> 仅供组内人员使用与测试。

## 功能总览

### 图书检索与浏览
- 首页图书展示、热门检索词、分类/排序/分页筛选
- 图书详情页：馆藏信息、状态标签（在架/借出）、读者评论区
- 榜单：热门检索榜、高分图书榜（按读者评分均分排序）

### 预约借阅 · 到馆办理
- 预约借阅：读者在线预约，生成取书码（PU-XXXXXX），单次最多 6 册，取书码保留 3 天
- 到馆核销：工作人员凭取书码扫码核销 → 扣库存 → 生成借阅记录
- 取消预约 / 取消借阅 / 续借

### 我的借阅（独立版块）
- 集中查看：当前预约、在借列表、借阅状态与到期日
- 扫码借还工作台（**仅管理员**）：摄像头识别图书（标签 / 封面 / 书脊通吃）完成借出与归还登记
- 归还办理流程：发起归还 → 进入办理态 → 工作人员扫码核销回架；错书自动拦截
- 识别失败或无摄像头时，支持手动输入书名 / 索书号 / 还书码定位图书

### 图书评论与评分
- 1–5 星评分 + 文字书评，同昵称同书再次发布即修改原评论
- 详情页与榜单展示评分徽标

### 自习室选座
- 阅览室平面图选座（单次最多 2 个连座）、按日期预约、到馆签到

### 登录与双身份（管理者 / 读者）
登录方式（云端账号体系，新号验证后自动注册）：

| 方式 | 说明 |
|---|---|
| 手机验证码 | 11 位手机号 + 短信验证码 |
| 邮箱验证码 | 邮箱收码登录，**新邮箱注册时可同时设置密码**，之后可密码直接登录 |
| 邮箱 + 密码 | 已设密码的老账号快速登录 |
| 微信扫码 | 需正式发布域名，本地环境暂不可用（平台限制） |
| 演示模式 | **本地测试专用**：免验证码一键以「读者 / 管理员」身份进入，不连云端账号 |

- **读者**：预约借阅、我的借阅、取消/续借、发起归还、书评评分、选座签到
- **管理员**：读者全部能力 + 扫码借还工作台 + 预约核销（金色徽标标识）
- 管理员开通：读者登录后点右上角「管理员认证」，输入口令完成升级（口令校验在云端安全函数内完成，前端无法伪造）
- 未登录可自由浏览检索与书评，触发操作时引导登录

## 快速开始

```bash
npm start          # 等价于 node server.js，默认端口 3000（无第三方依赖，无需 npm install）
```

浏览器访问 `http://localhost:3000`。

> 纯静态站点也可直接双击 `index.html` 打开浏览；登录与图像识别的完整体验建议经本地服务器访问。

## 技术架构

```
┌─ 前端（原生 HTML/CSS/JS，无框架）
│   ├─ db.js      事件溯源数据层：ntfy.sh 公共事件流同步 + IndexedDB 本地快照兜底
│   ├─ app.js     页面路由（#/loans 等哈希路由）、渲染、认证、视觉识别链路
│   └─ effects.js 视觉动效（新中式水墨风格）
├─ server.js      静态托管 + /api/vision 视觉识别代理（隐藏密钥、规避 CORS）
└─ WorkBuddy 云服务
    ├─ Auth       手机/邮箱验证码、密码登录、会话管理
    ├─ 数据库     yuedu_staff 管理员表（RLS）+ 安全函数 yuedu_claim_admin 口令核验
    └─ 内置 LLM   混元视觉大模型（免密钥）识别图书，本地代理为回退
```

- **识别链路**：摄像头/上传图片 → 压缩 → 云端混元视觉模型返回 `{title, source, status, confidence}` → 与馆藏模糊匹配 → 进入借还办理
- **业务事件**（借阅/预约/书评等）通过公共事件流多端同步，旧浏览器快照自动迁移

## 注意事项

- 本地系统代理请放行 `localhost` 与 `*.workbuddy.host`，否则浏览器端云端登录 / 识别会失败
- 演示模式产生的借阅、书评等业务事件仍会进入共享事件流，昵称自动带「演示·」前缀便于事后辨识
- 视觉识别密钥优先读环境变量，未配置时使用内置默认；请勿将密钥提交到仓库
